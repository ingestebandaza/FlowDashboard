================================================================================
  COMIENZA AQUI: PROBAR ELECTRON CON DISPOSITIVOS
================================================================================

OBJETIVO: Iniciar Electron y verificar que funciona con dispositivos

================================================================================
  PASO 1: INICIAR ELECTRON (1 minuto)
================================================================================

Simplemente ejecuta:

  cd c:\DASHBOARD\FlowDashboard
  .\abrir_electron.bat

O haz doble click en: abrir_electron.bat

El script automáticamente:
  ✅ Cierra procesos previos
  ✅ Inicia Backend C# (puerto 5000)
  ✅ Inicia Backend Python (puerto 8765)
  ✅ Inicia Electron App
  ✅ Verifica que todo está corriendo

Espera a ver:
  "SERVIDOR C#: http://127.0.0.1:5000"
  "SERVIDOR PYTHON: http://127.0.0.1:8765"
  "DASHBOARD: Electron App"

================================================================================
  PASO 2: VERIFICAR CONEXIONES (2 minutos)
================================================================================

Una vez que Electron está abierto:

1. Presiona F12 para abrir DevTools
2. Ve a la pestaña "Console"
3. Ejecuta estos comandos:

   await csharpAPI.healthCheck()
   // Debe retornar: true

   await pythonAPI.healthCheck()
   // Debe retornar: true

   const devices = await csharpAPI.get('/devices');
   console.log(devices);
   // Debe mostrar lista de dispositivos

   app.streamRenderer.connection.state
   // Debe retornar: "Connected"

================================================================================
  PASO 3: VERIFICAR UI (2 minutos)
================================================================================

En la ventana de Electron:

✅ Dispositivos aparecen en la grilla
✅ Cada dispositivo muestra: nombre, serial, estado
✅ Categorías aparecen en el sidebar (FlowLogin, FlowRegister, etc.)
✅ Botones de control están visibles (Conectar, Actualizar, Streaming)
✅ Panel de cuentas está visible

================================================================================
  PASO 4: PROBAR INTERACCIÓN (3 minutos)
================================================================================

1. Click en un dispositivo
   ✅ Debe cambiar de color/estilo
   ✅ Contador de seleccionados debe aumentar

2. Click en otro dispositivo
   ✅ Ambos deben estar seleccionados
   ✅ Contador debe mostrar 2

3. Click en "Deseleccionar todo"
   ✅ Todos deben deseleccionarse
   ✅ Contador debe volver a 0

================================================================================
  PASO 5: PROBAR RECONEXIÓN (5 minutos)
================================================================================

1. En TERMINAL 1 (C#), presiona Ctrl+C
   ✅ En Electron console, ver: "⚠️ Reintentando C# API (intento 1/3)"

2. Reinicia C# en TERMINAL 1
   dotnet run
   ✅ En Electron console, ver: "✅ Conectado al servidor C# (ADB)"

3. En TERMINAL 2 (Python), presiona Ctrl+C
   ✅ En Electron console, ver: "⚠️ Reintentando Python API (intento 1/2)"

4. Reinicia Python en TERMINAL 2
   python local_adb_server.py
   ✅ En Electron console, ver: "✅ Conectado al servidor Python (FlowLogin)"

================================================================================
  PASO 6: VERIFICAR PERFORMANCE (3 minutos)
================================================================================

1. Presiona F12 para abrir DevTools
2. Ve a la pestaña "Performance"
3. Click en "Record"
4. Espera 10 segundos
5. Click en "Stop"

Verificar:
  ✅ CPU: 5-15% (idle)
  ✅ Memoria: 150-200MB
  ✅ FPS: 50-60 (sin jank)

================================================================================
  PASO 7: PROBAR CON DISPOSITIVOS (5-10 minutos)
================================================================================

1. Conecta 1-2 dispositivos por USB o WiFi
2. En Electron, verifica que aparecen en la grilla
3. Selecciona un dispositivo
4. Si quieres probar FlowLogin:
   - Agrega cuentas en el panel de cuentas
   - Click en "Ejecutar FlowLogin"
   - Observa las bolitas cambiar de color

================================================================================
  CHECKLIST DE ÉXITO
================================================================================

✅ Electron inicia sin errores
✅ Conexiones a backends funcionan
✅ Dispositivos se cargan correctamente
✅ UI es responsiva
✅ Interacción funciona
✅ Reconexión funciona
✅ Performance es buena

Si todo está ✅, ¡ÉXITO! Electron está listo.

================================================================================
  TROUBLESHOOTING
================================================================================

❌ Error: "Cannot find module 'electron'"
   Solución: npm install

❌ Error: "Port 5000 already in use"
   Solución: netstat -ano | findstr :5000
            taskkill /PID <PID> /F

❌ Error: "Dispositivos no se cargan"
   Solución: Verificar que adb devices muestra dispositivos
            Verificar que C# backend está corriendo

❌ Error: "WebSocket connection failed"
   Solución: Verificar que C# backend está corriendo
            Verificar puerto 5000: netstat -ano | findstr :5000
