╔══════════════════════════════════════════════════════════════════════════════╗
║                              FLUJO DE DATOS                                  ║
╚══════════════════════════════════════════════════════════════════════════════╝

1. Usuario selecciona dispositivos en Electron UI
   ↓
2. Electron llama a C# API: POST /api/streaming/start
   ↓
3. C# ScrcpyService inicia procesos scrcpy
   ↓
4. Ventanas scrcpy se posicionan en grid (2x2, 3x3, etc)
   ↓
5. Usuario presiona "Iniciar FlowLogin"
   ↓
6. Electron llama a C# API: POST /api/devices/flowlogin/start
   ↓
7. C# PythonBridgeService llama a Python: POST /flowlogin/start
   ↓
8. Python ejecuta Login.js en cada dispositivo via FlowAgent
   ↓
9. Login.js actualiza flowlogin_status.json en Android
   ↓
10. Python lee status y actualiza estado
    ↓
11. C# recibe update de Python
    ↓
12. C# envía evento SignalR: AccountStatusUpdated
    ↓
13. Electron recibe evento y actualiza bolitas en UI
    ↓
14. Usuario ve bolitas cambiar de color en tiempo real:
    • Gris    = Pendiente
    • Azul    = Ejecutando
    • Verde   = Success
    • Rojo    = Error
    • Naranja = Already logged
    • Morado  = Review
