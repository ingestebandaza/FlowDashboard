╔══════════════════════════════════════════════════════════════════════════════╗
║                         FLUJO DE DATOS - FASE 1                              ║
╚══════════════════════════════════════════════════════════════════════════════╝

1. CARGA INICIAL
   ┌─────────────────────────────────────────────────────────────────┐
   │ Electron App inicia                                             │
   │   ↓                                                             │
   │ Verifica conexión a C# API (5000) y Python API (8765)          │
   │   ↓                                                             │
   │ Carga dispositivos desde C# API                                 │
   │   ↓                                                             │
   │ Carga nombres desde Python API (device_names.json)             │
   │   ↓                                                             │
   │ Carga cuentas desde Python API (person field)                  │
   │   ↓                                                             │
   │ Carga estados desde Python API (flowlogin_status.json)         │
   │   ↓                                                             │
   │ Renderiza UI con todos los datos                               │
   └─────────────────────────────────────────────────────────────────┘

2. POLLING CONTINUO
   ┌─────────────────────────────────────────────────────────────────┐
   │ Cada 5 segundos:                                                │
   │   • Actualiza lista de dispositivos desde C# API                │
   │   • Recarga nombres y cuentas desde Python API                  │
   │   • Re-renderiza grid de dispositivos                           │
   │                                                                 │
   │ Cada 2 segundos (si Python conectado):                          │
   │   • Actualiza estados de login desde Python API                 │
   │   • Actualiza colores de bolitas en tiempo real                 │
   │   • NO re-renderiza todo, solo actualiza bolitas                │
   └─────────────────────────────────────────────────────────────────┘

3. INTERACCIÓN USUARIO
   ┌─────────────────────────────────────────────────────────────────┐
   │ Usuario hace click en dispositivo                               │
   │   ↓                                                             │
   │ Toggle selección en Set (selectedDeviceIds)                     │
   │   ↓                                                             │
   │ Re-renderiza grid (marca/desmarca tarjeta)                      │
   │   ↓                                                             │
   │ Actualiza contador de seleccionados                            │
   └─────────────────────────────────────────────────────────────────┘

4. STREAMING (Preparado, no implementado en FASE 1)
   ┌─────────────────────────────────────────────────────────────────┐
   │ Usuario presiona "Iniciar Streaming"                            │
   │   ↓                                                             │
   │ POST /api/streaming/layout con serials seleccionados           │
   │   ↓                                                             │
   │ C# calcula posiciones (x, y, width, height)                    │
   │   ↓                                                             │
   │ Para cada dispositivo:                                          │
   │   POST /api/streaming/start con config                         │
   │   ↓                                                             │
   │   C# inicia scrcpy en ventana separada                         │
   │   ↓                                                             │
   │ Renderiza placeholders en UI (FASE 2: embeber ventanas)        │
   └─────────────────────────────────────────────────────────────────┘
