# FlowDashboard 1.0.47

## Mejoras al reordenamiento de dispositivos

- Selecciona 2 o mas dispositivos y arrastralos juntos a otra posicion o categoria. Todos se mueven a la vez.
- Corregido bug donde el orden no se aplicaba correctamente al mover multiples dispositivos.
- Los numeritos visuales se mantienen en el orden que los pusiste hasta que uses el boton Reordenar.
- El boton Reordenar renumera todos los dispositivos segun el orden visual actual (respetando categorias).

## Como actualizar

Abre FlowDashboard. El updater detecta la nueva version y la instala automaticamente.
