## ✨ Animaciones

### **Transiciones:**
- **Menú:** 0.3s cubic-bezier(0.4, 0, 0.2, 1)
- **Hover:** 0.16s ease
- **Zoom:** Instantáneo

### **Efectos:**
- **Hover:** Elevación + cambio de color
- **Selected:** Borde verde + glow
- **Running:** Pulso suave
